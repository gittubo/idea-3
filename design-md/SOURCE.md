# Source

Vendored from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) at commit `fcc70284932276d085f01ef9f83edde90b1258cb` (MIT, see `LICENSE`).

Each folder holds a `DESIGN.md`: a plain-text design system (tokens, type, colour, layout rules) that an AI agent can read to build UI in that style. To use one, point the agent at e.g. `design-md/<name>/DESIGN.md`, or copy it to the project root as `DESIGN.md`.

To update: re-clone the repository and replace the folders.
